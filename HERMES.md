# Hermes Agent Plan

Hermes Agent is not connected yet. This file tracks the safe setup path.

## Step 1: Choose Where Hermes Runs

Recommended beginner options:

- Local Mac: cheapest and easiest to test.
- Small VPS: useful later if the assistant should run while the Mac is off.

## Step 2: Choose Model Providers

Start with low-cost options:

- Local models through Ollama or LM Studio.
- Free hosted tiers where available.
- One paid provider only after setting a strict budget limit.

## Step 3: Connect GitHub

Hermes should work with this repository by:

- Reading files from the local clone.
- Creating or updating task files.
- Helping with GitHub Issues.
- Running safe scripts only after approval.

## Step 4: Add Automations

Start with simple automations:

- Daily planning note.
- Weekly review note.
- Project status summary.

Avoid automations that spend money, send messages, or modify important files until the system is tested.
