# Tools

This file explains how each tool fits into the system.

## GitHub

GitHub is the project memory, file storage, task board, and automation base.

Use it for:
- Repositories
- Issues
- Commits
- Pull requests
- GitHub Actions
- Project history

## VS Code

VS Code is the local workspace where files are edited.

Use it for:
- Editing project files
- Running extensions
- Using GitHub Copilot
- Reviewing changes before committing

## GitHub Desktop

GitHub Desktop is the beginner-friendly bridge between the Mac and GitHub.

Use it for:
- Seeing changed files
- Creating commits
- Pushing changes to GitHub
- Pulling updates from GitHub

## Codex

Codex is the coding and project assistant.

Use it for:
- Editing files
- Explaining code
- Creating project structure
- Running checks
- Helping with GitHub workflows

## Hermes Agent

Hermes Agent can become the always-on automation layer.

Use it for:
- Multi-model AI routing
- Scheduled tasks
- Tool use
- Memory
- Integrations such as chat apps and MCP tools

Do not connect paid AI providers until spending limits are clear.
